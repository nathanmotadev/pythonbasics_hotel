 🏨 Sistema de Atendimento - Pousada

## 📌 Descrição
Este é um projeto simples desenvolvido em Python com o objetivo de praticar conceitos básicos de programação.

O sistema simula o atendimento de uma pousada, permitindo que o usuário escolha opções de refeições através de um menu interativo.

---

## ⚙️ Funcionalidades
- Entrada de nome do usuário
- Exibição de menu de refeições
- Seleção de pedidos
- Confirmação do pedido
- Possibilidade de realizar novos pedidos

---

## 🧠 Conceitos utilizados
- Entrada e saída de dados (`input` e `print`)
- Estruturas condicionais (`if` e `elif`)
- Laços de repetição (`while`)
- Uso de variáveis e organização de lógica

---
